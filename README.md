# Shadowfall — Landing Page

Многостраничный промо-сайт для инди-MMO в стиле Lineage II / ArcheAge.
Написан на чистом HTML, CSS и JS — без фреймворков и библиотек.

![Превью](img/preview.png)

---

## О проекте

Небольшой лендинг для вымышленной игры Shadowfall. Сделал для портфолио,
чтобы показать навыки вёрстки и немного JS.

**Что внутри:**
- 6 страниц: Главная, Об игре, Особенности, Медиа, Скачать, Контакты
- Hero с параллаксом и частицами
- Галерея с лайтбоксом
- Форма обратной связи
- Адаптив под мобильные

---

## Про разработку

Часть кода написана вместе с AI-ассистентом (Claude) — в формате vibe coding.
Я задавал структуру, стиль и логику, AI помогал с рутиной: разметкой, стилями,
мелкими скриптами. Это было быстрее, чем писать всё в одиночку с нуля.

Цель была не «сделать крутой продукт», а **поиграться с подходом** и заодно
получить что-то в портфолио.

```bash
python -m http.server 8000
```
